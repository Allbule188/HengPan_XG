# 平台突破策略 v4：平台内累计换手 ≥30% 流通股本

## 新因子

在平台检测日，用**最长通过窗口** W 计算：

```text
平台累计成交股数 = sum(平台窗口内成交量(手)) × 100
平台累计换手   = 平台累计成交股数 / 流通股本
要求：平台累计换手 >= 30%
```

- 流通股本来源：eltdx `corporate.finance_batch` 的 `circulating_shares`
- 快照文件：`workplaces01/api/data/stock_circulating_shares.csv`
- 覆盖：5,029 只沪深非 ST 股票，无缺失
- 因子通过率：平台箱体候选 251,453 次检测中，97,554 次通过（约 38.8%）

## 数据与交易规则

- 数据：720 根前复权日线，2023-07-21 ~ 2026-11-04
- 指数：上证指数 `sh000001`，信号日收盘 > MA20 才做多
- 平台：窗口 20/30/60，振幅 ≤10%、均线粘合 ≤2%、波动率 ≤2%/根、箱体质量 ≥0.8
- 突破 A/B/C：A=收盘>箱顶；B=A+放量1.5倍；C=箱顶2%+放量+涨幅2%
- 持仓：突破日收盘买入；-5% 止损；+10% 止盈；最长 5 日，第 5 日收盘强制平仓
- 成本：往返 15bp；排除类涨停信号

## 结论

- **30% 流通股本换手因子确实改善了结果**：A 的平均超额从无因子的 +0.043% 升到 +0.124%（t=3.94）；A+30根+MA20 的净中位数转正（+0.128%），平均超额 +0.241%（t=4.95）。
- **改善集中在 2025-2026 原样本**：A+30根 在该段平均超额 +0.257%（t=5.30），但新增的 2023-2024 段为 -0.768%（n=114，t=-1.18）。新增段样本小，不能证伪，但也没有确认。
- **B+30根 也出现类似改善**：原样本平均超额 +0.303%（t=3.58），新增段 -2.92%（n=54）。
- **C 仍然偏弱**：各窗口平均超额接近 0 或为负。
- **30 根窗口是因子最有效的组合**；20 根一般，60 根明显变差。
- **中位数仍不够强**：A 全部窗口净中位数 -0.009%，A+30根 +0.128%；整体仍靠少数大赢家，2024-09 单月是极端 outlier。
- **结论：因子有增量，但尚未跨样本确认；A+30根+MA20 是当前最值得继续验证的格子，不是可直接部署的策略。**

## 限制

- **流通股本用的是当前快照**（2026-10/11），不是历史时点值；送转、增发、解禁会带来偏差。
- 成交量单位是手，因子计算时 ×100 转成股；已核对流通股本单位为股。
- 平台箱体在检测日固定；突破后不动态更新。
- 收盘买入、日线高低点触发止损/止盈；没有盘口冲击、涨跌停无法成交、停牌细节。
- 同日同时触发止损/止盈按止损先成交，偏保守。
- 这是每笔交易的事件研究，不是资金约束组合；没有仓位管理和交易容量限制。
- 单一市场样本、当前上市池、前复权，存在幸存者偏差；新增段样本较小。
