# 平台突破策略回测 v3：严格每日检测 + 指数 MA20 过滤

## 本次改动

1. **去掉候选预筛**：`PRE_FILTER = None`，严格每日全量平台检测。
   - 实际结果与上一版完全相同，因为平台振幅阈值 ≤10% 已经保证收盘价距窗口最高价不超过约 9.1%，原来的“距高点 ≤10%”预筛本来就不会触发。
2. **加市场环境过滤（指数 MA20）**：
   - 指数：上证指数 `sh000001`，720 根日线，2023-11-14 ~ 2026-11-04
   - 信号日收盘时 `指数收盘 > MA20` 才做多
   - 同一批交易同时记录 `regime_on`，分别统计“全部”“MA20 上方”“MA20 下方”

## 数据与交易规则

- 数据：`his_Kline_data_qfq_720/all_stocks_720_day.csv`，2023-07-21 ~ 2026-11-04
- 范围：沪深、非 ST；检测日近 20 日平均成交额 ≥3000 万
- 平台：窗口 20/30/60，振幅 ≤10%、均线粘合 ≤2%、波动率 ≤2%/根、箱体质量 ≥0.8
- 突破 A/B/C：
  - A：收盘 > 箱顶
  - B：A + 当日量 / 前 20 日均量 ≥1.5
  - C：收盘 > 箱顶×1.02 + 放量 ≥1.5 + 当日涨幅 ≥2%
- 持仓：突破日收盘买入；-5% 止损；+10% 止盈；最长 5 个交易日，第 5 日收盘强制平仓
- 成本：往返 15bp；排除类涨停信号
- 跳空：开盘破止损按开盘价；开盘越止盈按开盘价；同日同时触发按止损先成交

## 结论

- **去掉预筛没有改变结果**：10% 振幅条件本身已经限制了收盘价与窗口高点的距离，预筛是冗余的。
- **MA20 过滤提高了绝对收益和胜率**：A 净均值从 +0.262% 升到 +0.445%，净胜率从 47.5% 升到 49.1%；B/C 也类似。
- **但它没有增加 alpha**：同期市场涨幅也更高，A 的平均超额从 +0.043% 变成 -0.047%，t=-2.05；B/C 的超额进一步恶化。过滤掉的是下跌市，留下的是上涨市，策略赚的是 beta。
- **MA20 下方**：A 绝对收益 -0.561%，但市场同期 -0.866%，平均超额 +0.448%；说明它只是高 beta 多头，不是抗跌策略。
- **唯一略好的格子**：A + 30 根 + MA20 上方，净中位数 +0.058%、平均超额 +0.012%，但 t=0.37，统计上等于 0。
- **止损仍多于止盈**：A 止损率 12.3%，止盈率 8.5%，79.2% 的交易靠 5 日时间平仓；时间平仓净均值只有 +0.254%。
- **月份不稳定**：2024-09 单月 +10.89% 是极端 outlier；其余月份大量为负。

**结论：MA20 过滤改善了绝对收益，但没有提供市场超额；这套策略仍然不是可部署的 alpha 策略。**

## 限制

- 指数用上证指数 `sh000001`；换沪深 300/中证 1000 可能不同。
- 平台每日检测、箱体在检测日固定；没有动态更新。
- 收盘买入、日线高低点触发止损/止盈；没有盘口冲击、涨跌停无法成交、停牌细节。
- 同日同时触发止损/止盈按止损先成交，偏保守。
- 没有资金约束组合；每笔统计是事件研究，不是组合净值。
- 单一市场样本、当前上市池、前复权，存在幸存者偏差。
