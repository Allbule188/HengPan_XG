# 平台突破策略回测：突破日收盘买入，次日收盘卖出

## 数据与范围

- 数据：A 股日线、前复权，2025-05-13 ~ 2026-11-03
- 范围：沪深、非 ST；检测日近 20 日平均成交额 ≥ 3000 万
- 平台检测：每 2 个交易日一次；检测后 5 个交易日内寻找突破
- 平台定义：窗口 20/30/60 根，振幅 ≤10%、均线粘合 ≤2%、波动率 ≤2%/根、箱体质量 ≥0.8

## 突破定义

| 变体 | 条件 |
|---|---|
| A | 收盘价 > 平台箱顶 |
| B | 收盘价 > 平台箱顶，且当日量 / 前 20 日均量 ≥1.5 |
| C | 收盘价 > 箱顶×1.02，放量 ≥1.5，且当日涨幅 ≥2% |

## 交易与成本

- 突破日收盘买入，**次日收盘卖出**，持有 1 个交易日。
- 成本：往返 15bp（佣金 + 印花税 + 滑点假设）。
- 排除“类涨停”信号：主板当日涨幅 ≥9.5%，创业板/科创板 ≥19.5%。
- 平台箱体在检测日固定；突破后不再重算箱体。

## 结论

- 毛收益接近 0，中位数为负，胜率不到 50%；扣 15bp 成本后全部为负。
- 均值略正主要来自少数大赢家，收益分布右偏；典型交易是亏的。
- 累计表现跑输市场：A 几乎不赚钱，B/C 明显亏损；平台越长（60 根）突破质量越差。
- 没有证据表明“平台突破 + 次日卖出”在这段样本上有正 alpha。

## 限制

- 单一市场样本（约 1 年 4 个月）、当前上市池、前复权；存在幸存者偏差。
- 平台每 2 天检测一次，突破监测 5 天；可能漏掉检测间隔内形成并突破的平台。
- 箱体在检测日固定；突破后不动态更新。
- 收盘买入是理想化假设；没有考虑盘口冲击、涨跌停无法成交、停牌。
- 等权日组合没有资金约束和仓位管理；交易之间可能重叠。
- 结果只说明这段样本、这套参数下没有正收益，不代表所有平台突破策略都无效。
