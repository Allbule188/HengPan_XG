# 全市场平台扫描（成交量 + 低位 + 快速下跌）

## 数据与范围

- 数据：`workplaces01/api/data/his_Kline_data_qfq/all_stocks_360_day.csv`
- A 股日线、前复权、5,578 只、2025-05-13 ~ 2026-11-03
- 范围：全市场（沪、深、北交所），含 ST；要求扫描日有 K 线且至少 300 根
- 扫描日：2026-11-03；实际分析 5,389 只，189 只历史不足 300 根被跳过

## 配置

| 参数 | 值 |
|---|---|
| 窗口 | 20 / 30 / 60 根（日线） |
| 振幅阈值 | 10% |
| 均线粘合度 | 2% |
| 波动率阈值 | 2%/根 |
| 箱体检测 | 开启，箱体质量 ≥0.8 |
| 成交量分析 | 开启 |
| 低位判断 | 开启；高点回看 300 根，回撤 ≥30%，下跌需在 180 个日历日内 |
| 快速下跌 | 开启；30 根窗口内最大跌幅 ≥15% |
| 突破前兆/确认 | 关闭（只做标注，不参与筛选） |

### 为什么高点回看写成 300 根

develop 的 `decline_analyzer` 要求 `len(df) >= max(60, lookback_days)`。默认 365 根，而这份数据每只票正好 360 根，会导致所有股票返回 `insufficient_data`，低位和快速下跌恒为 0。因此本次把高点回看降到 300 根；如果换成更长的历史或 60 分钟库（约 1,440 根），应恢复 365。

## 漏斗

| 配置 | 价格平台 | 带箱体 | 量能通过 | 低位通过 | 快速下跌通过 | 最终 |
|---|---:|---:|---:|---:|---:|---:|
| 页面原量能 0.5/0.5 | 253 | 213 | 8 | 2,093 | 5,100 | **2** |
| 中间量能 0.8/0.7 | 253 | 213 | 87 | 2,093 | 5,100 | **15** |
| 后端默认 0.9/0.75 | 253 | 213 | 134 | 2,093 | 5,100 | **26** |

成交量是主要约束；低位和快速下跌在本期数据里不是主要瓶颈。

## 结果

- `matches_strict_page_volume.csv`：页面原量能阈值，2 只（重药控股、特瑞斯）
- `matches_mid_volume_08.csv`：0.8/0.7，15 只
- `matches_relaxed_volume_09.csv`：0.9/0.75，26 只（含 ST百灵、北交所特瑞斯）
- `matches_all.csv`：三组合并
- `summary.json` / `funnel.csv`：配置与漏斗
- `threshold_analysis/`：量能、回撤、快速下跌窗口的敏感性网格

## 注意

- 结果只是“低位 + 快速下跌 + 平台 + 缩量”的形态候选，不含未来收益检验。
- 北交所在仓库的本地 60 分钟模式里不可选；本次按“全市场”口径保留，若要和页面本地模式一致，需排除 BJ。
