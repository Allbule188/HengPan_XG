# 平台突破策略回测 v2：每日检测 + 止盈止损 + 最长 5 日

## 数据与范围

- 数据：`workplaces01/api/data/his_Kline_data_qfq_720/all_stocks_720_day.csv`
- A 股日线、前复权，2023-07-21 ~ 2026-11-04，5,578 只
- 范围：沪深、非 ST；检测日近 20 日平均成交额 ≥ 3000 万
- 平台检测：**每日一次**
- 平台定义：窗口 20/30/60 根；振幅 ≤10%、均线粘合 ≤2%、波动率 ≤2%/根、箱体质量 ≥0.8
- 候选预筛：收盘价距窗口最高价 ≤10%，避免对远离箱顶的股票做箱体计算
- 突破监测：检测后 5 个交易日内每日检查

## 突破定义

| 变体 | 条件 |
|---|---|
| A | 收盘价 > 平台箱顶 |
| B | 收盘价 > 箱顶，且当日量 / 前 20 日均量 ≥1.5 |
| C | 收盘价 > 箱顶×1.02，放量 ≥1.5，且当日涨幅 ≥2% |

## 交易规则

- 突破日收盘买入。
- 次日起每日检查：
  - 亏损 5% 止损；
  - 盈利 10% 止盈；
  - 第 5 个交易日收盘强制平仓。
- 跳空处理：开盘已跌破止损价按开盘价成交；开盘已越过止盈价按开盘价成交。
- 同一天同时触及止损和止盈：按止损先成交（保守）。
- 成本：往返 15bp。
- 排除类涨停信号（主板 ≥9.5%，创业板/科创板 ≥19.5%）。
- 平台箱体在检测日固定；突破后不重算。

## 结论

- **A 的每笔净均值 +0.262%，平均超额 +0.043%，t=2.02**；但净中位数 -0.15%、净胜率 47.5%，均值主要靠少数大赢家。
- **新增的 2023-2024 段没有确认优势**：A 的平均超额 -0.095%，B/C 分别 -1.72% / -1.58%；高毛收益主要是市场 beta。
- **B/C 跑输市场**：虽然绝对收益为正，但同期市场涨幅更高，平均超额为负。
- **A 的优势集中在 2025-2026**：平均超额 +0.059%，t=2.78；样本一换就消失，说明不稳定。
- **A 的 30 根窗口最好**：平均超额 +0.198%，但净中位数仍为负。
- **止盈率低于止损率**（A 7.9% vs 14.5%），大多数交易是 5 日时间平仓，靠时间平仓的微弱正收益（+0.26%）撑住整体。
- 按退出日等权平均的“示意曲线”A 累计 +125%，但最大回撤 -58%，且不是资金约束组合，不能当作真实组合收益。

**结论：这套参数下没有稳定的、可部署的正 alpha。A 有一点统计上的边际优势，但不够稳健；B/C 是市场 beta。**

## 限制

- 单一市场样本（约 3 年 3 个月）、当前上市池、前复权；存在幸存者偏差。
- 平台每日检测，但候选预筛（距窗口高点 ≤10%）会漏掉少量远离箱顶后快速拉升的突破。
- 箱体在检测日固定；突破后不动态更新。
- 收盘买入、止损/止盈按日线高低点成交；没有盘口冲击、涨跌停无法成交、停牌的精细处理。
- 同一天同时触及止损和止盈按止损先成交，偏保守。
- 等权 cohort 曲线不是资金约束组合；没有仓位管理、资金分配和交易容量限制。
- 结果只说明这段样本、这套参数；不代表所有平台突破策略都无效。
